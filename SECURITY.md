# Security policy

## Supported versions

Only the latest stable release published on the project's GitHub Releases page
is supported for security fixes. Prereleases and earlier stable releases are
out of support. Update to the latest stable release before reporting an issue
against an older version.

This is a best-effort project maintained by its owner. There is no guaranteed
response or remediation time.

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub's private vulnerability
reporting form](https://github.com/ctemple9/msc2/security/advisories/new). Do not
open a public issue or discussion containing exploit details. GitHub sends
private reports to the repository maintainers; they are not visible to the
public.

Include the affected MSC 2 version, platform, impact, and steps to reproduce
when safe to do so. Avoid including real server credentials, player data, or
other private host information. The maintainer will coordinate a fix and
disclosure through the private advisory where possible.
