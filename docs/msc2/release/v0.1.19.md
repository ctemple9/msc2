# MSC 2 v0.1.19

Publication requested by Cameron Temple on 2026-10-02. This release is an
unsigned beta prerelease, using the existing build-only publication workflow.
Publication and physical artifact acceptance are separate; a successful build
does not close outstanding phase acceptance gates.

## Changes

- Redesign agent home around the selected agent, actual server list and visible
  explanation of the desktop app, agent and Minecraft relationship.
- Offer Install when the local agent is missing, or one Start/Stop button plus
  Repair when installed. Native service actions refresh the connection.
- Put new remote-host setup and saved hosts beneath one dropdown, retaining
  secure pairing, SSH/tunnel review, editing and removal confirmation.
- Replace signal/status dots across MSC with text labels.
- Include the merged integrated 2D/3D world map and terrain/player controls.
  Known runtime, dimension and mod limitations remain recorded in
  [Phase 18 map acceptance](../phase18-map-acceptance.md).
- Include map helper executables in Windows desktop staging, matching the
  desktop runtime's expected resource locations.

## Publication contract

Tag: `v0.1.19`. The commit with subject `P16.35: prepare v0.1.19 release` is
its source identity; no existing release tag is moved.

The workflow builds five desktop installers and four standalone headless
archives, plus `SHA256SUMS`, signed update manifest and detached signature.
macOS Intel and Apple Silicon, Windows x86_64 and Linux x86_64 are retained.
No tests, smoke checks or lint gates are added to publication. Local preparation
checks inspect version/lockfile consistency and build the frontend; they are
not new release gates. Cross-platform execution remains the release builders'
responsibility, and Cameron owns physical acceptance.
