# MSC 2 v0.1.22

Publication requested by Cameron Temple through the existing build-only beta
release workflow. No tests were run.

Fix headless Linux CLI status and routine service control for archive-installed
agents whose systemd units lack private MSC metadata. Preserve the installing
account and custom data directory without rewriting the installed service.
Existing installations receive the fix by updating their agent binary.

The immutable tag v0.1.22 identifies the source. Publish all nine desktop and
headless artifacts, SHA256SUMS, and the signed update manifest and signature.
Successful publication does not establish physical acceptance on all platforms.

Accept modern Java datapack min_format/max_format metadata, including Tectonic
3.0.29 for Minecraft 26.3, without requiring the legacy pack_format field.
Keep legacy pack support and reject malformed ranges before modifying worlds.

Restore the serde_repr dependency lock entry accidentally altered by the first
release version bump. The original unpublished run was cancelled and removed;
Cameron explicitly authorized replacing its tag with this corrected source.
