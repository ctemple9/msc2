# MSC 2 v0.1.23

Publication requested by Cameron Temple through the existing build-only beta
release workflow. No tests were run.

Fix headless updates that replaced only the agent and omitted the bundled
Vantage and Bedrock map executables. Validate the complete helper payload before
stopping the agent, replace helpers and the Vantage license alongside it, and
include them in rollback.

Java maps recover a missing Vantage renderer into MSC's own cache from the same
platform-specific SHA-256 pin used by packaging. First use downloads official
Minecraft client metadata/assets for the saved world's version (falling back to
the configured version), verifies published SHA-1 checksums and byte counts,
and extracts only bounded, safe Minecraft assets/game data. Later launches reuse
the versioned cache. A Minecraft launcher, player login or player join on the
server host is not required. First use needs that host's internet connection.
Explicit MSC2_VANTAGE_BIN overrides remain authoritative. Third-party mod assets
are not downloaded.

Report distinct dependency/setup/startup failures rather than suggesting missing
client assets for every renderer failure. Preserve bounded renderer diagnostics
in agent logs with its private bearer token redacted. Minecraft saves remain
read only during map dependency preparation, and preparation does not restart
the game server or interrupt Chunky.

The immutable tag v0.1.23 identifies the source. Publish all nine desktop and
headless artifacts, SHA256SUMS, and signed update metadata/signature. Successful
publication does not establish physical acceptance on all platforms. Formatting,
ordinary agent Clippy and frontend checks passed with existing warnings. New unit
regression source compiled; compiling all agent test targets is blocked by an
existing CLI service fixture referring to removed CommonArgs fields. No tests
or map smoke suites were run.
