# MSC 2 v0.1.26

This prerelease corrects ATM10 saved-world startup and modpack download reporting,
and Chunker runtime discovery and cache placement.

- Preserve loader-owned data-pack identifiers already saved by Minecraft, including
  OpenLoader identifiers containing spaces and uppercase letters. MSC no longer
  rejects these names before launching a saved ATM10 world. Keep validation for
  requested packs and MSC-managed file packs, and retain disabled-pack metadata.
- Explain what happened to every file originally flagged during CurseForge pack
  inspection: Modrinth recovery, direct download, exclusion with a reason, or
  an unresolved outcome. Keep recovered downloads separate from direct downloads.
  This does not retroactively identify the two unaccounted-for files from the
  original report.
- Name invalid requested data-pack IDs and identify pre-launch world-settings
  failures instead of presenting unrelated Java/port troubleshooting advice.
- Discover MSC-managed Java for Chunker and try alternative runtimes when a
  launcher cannot run it. Chunker requires Java 17 or newer. Report real launch
  errors instead of claiming zero supported formats. Bound discovery time/output
  and use the selected runtime for conversion.
- Store Chunker's JAR and metadata in the agent's configured data folder. Migrate
  a legacy cache when the destination is absent, verify copied bytes before
  removing originals, and remove the old directory only if empty. Preserve
  custom Chunker paths, existing destination installations and unrelated files.

## Downloads and updates

Includes Intel and Apple Silicon macOS installers and headless archives, plus
x86_64 Windows and Linux artifacts: nine desktop/headless packages in total.
Apple Silicon macOS packages have no local Bedrock VM sidecar; local Bedrock
requires an Intel Mac. Standalone headless archives include HEADLESS-INSTALL.md.

Verify packages against SHA256SUMS. The release includes the signed update
manifest and detached Ed25519 signature for native in-app installation. Desktop
packages remain unsigned and macOS packages are not notarized. Terrain helpers
and the existing desktop/CLI support boundaries remain unchanged.

## Verification

Rust formatting and relevant Clippy checks pass with an existing unused-function
warning. Frontend type checking and production builds pass with existing warnings;
generated API types remain consistent. Essential regressions were added and their
targets compiled, but no tests were run. The unchanged build-only release workflow
produces packages, checksums and signed metadata; it adds no CI or test gate.

Physical acceptance remains Cameron's verification: restart the existing affected
ATM10 world, import ATM10 8.2 and reconcile the flagged files, then confirm repeated
starts after First Start. On the affected Mac, confirm Chunker lists formats and
