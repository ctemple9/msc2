# MSC 2 v0.1.27

This prerelease corrects macOS update rollback and agent reconnection, makes interrupted host resets recoverable and cancellable, and supports large-world conversion beyond the previous 8 GiB limit.

## Upgrading from macOS 0.1.25 or 0.1.26

Install this release manually: stop your Minecraft server, quit MSC 2, open the matching disk image, and replace MSC 2 in Applications. Open the new app and repair the agent once so its installed package and trusted desktop identity match. Confirm Settings shows 0.1.27 after closing and reopening the app. The older updater runs its own defective helper, so Settings update cannot reliably perform this first upgrade. Subsequent updates can use the corrected updater.

## Updates and reset recovery

- Accept the agent's actual HTTP 204 health response instead of rolling a healthy update back to the previous version.
- Register the replacement app's matching agent and desktop signing identity before relaunch. Restore both on rollback and stop the failed replacement desktop. Keep saved credentials during the health trial.
- Reverify and reuse intact staged releases for installation retries. Reject changed artifacts without overwriting them. Require a stopped Minecraft server before a macOS update restarts its agent.
- Resume interrupted resets after a crash. Record explicit cancellation before deleting another file; cancellation survives restart. Files already removed cannot be restored.
- Preserve failed reset recovery and keep the agent accessible after a permission error. Show the failure and offer retry or cancellation where available. Root-owned leftovers are not silently deleted with elevated privileges.
- Open reset recovery instead of trapping it behind first-time setup. Confirm successful reset completion before clearing desktop credentials or uninstalling the local service. Existing full-reset and fresh-install behavior remains available.
- Add headless recovery commands: `msc host reset status` and `msc host reset cancel`.

## Large-world conversion

- Stream source and converted archive copies instead of loading whole ZIPs into RAM. Read slot sizes from file metadata, including when saving an outgoing world.
- Support larger world archives during conversion and activation. Keep path/type/CRC validation, the 200,000-entry ceiling and a 1 TiB absolute size backstop.
- Estimate working space before extraction/conversion on scratch and destination disks, including existing live-world safety copies and headroom for larger output. Keep a 2 GiB disk reserve, recheck between stages, during archive writes and while Chunker runs, and explain shortages with available/required space. Estimates are conservative on separate disks and cannot guarantee the eventual converted size.
- Release temporary input and unpacked output between stages. Preserve the original source and retain an existing slot if the replacement copy or final promotion fails.
- Bound Chunker's Java heap to half currently available memory, capped at 4 GiB. Refuse conversion below 1 GiB available memory. Drain both process output streams with bounded buffering and retain failure diagnostics.

## Downloads and updates

Nine packages: Intel/Apple Silicon macOS desktop and headless, x86_64 Windows desktop and headless, and Linux x86_64 DEB/RPM/headless. Apple Silicon packages omit the local Bedrock VM sidecar. Headless archives include installation instructions. Verify packages against SHA256SUMS; signed update manifest and Ed25519 signature support native updates. Desktop packages remain unsigned and macOS packages are not notarized.
