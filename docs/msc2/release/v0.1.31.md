# MSC 2 v0.1.31

This prerelease adds native server-file imports and storage management, places
service controls where they belong, and lets large Bedrock maps show saved
terrain near the camera without waiting for a full-world scan.

## Files and storage

- Desktop file imports and uploads use bounded native transfers with progress,
  incremental integrity checks, and disk-space checks. Large server sources
  are no longer rejected by the former fixed-size import limit.
- MSC Settings now separates general, services, and storage controls. Storage
  shows computers, servers, active worlds, saved worlds, backups, and other
  owned data with clearer labels and scoped removal reviews. Unregistered
  server folders remain protected and can be opened locally for inspection.
- Imported Java server JARs report presence independently of version metadata;
  known JAR metadata can identify the installed version without downloading or
  running the JAR.

## Services and setup

- Playit account setup remains global. MSC Settings shows the shared agent and
  its saved Java, Bedrock, and voice tunnel addresses behind a reveal control.
  A server shows only the tunnels its configuration uses.
- Xbox Broadcast setup and sign-in are in that server's Services tab, along
  with runtime, automatic-start, and helper-JAR controls. Unused account-note
  fields were removed.
- The Add Server wizard keeps one sheet size across its steps and scrolls long
  content within that frame.

## Bedrock saved-terrain map

- On large Overworlds, the map first indexes saved chunks near spawn, then
  discovers more saved terrain around the moving camera. It shows fast surface
  previews before refining nearby tiles into full 3D detail. Explored tiles are
  retained for the selected snapshot; normal viewing does not start a competing
  full-world scan. Unsaved terrain remains empty.
- The exporter can open more LevelDB tables on macOS and reuses one read-only
  world handle across tile requests. Batching nearby reads avoids reopening the
  large world for every tile. Diagnostic output no longer interferes with the
  tile helper's replies.
- Preview cliff textures stay at block scale and preview foliage no longer forms
  tall leaf walls. The Depth slider accepts fine pointer movement, eases the
  camera with the cutaway, and settles on a whole block when released.

Cameron's imported 7.5 GB Bedrock world displayed progressively loaded terrain
with the local candidate, and he accepted the revised Depth slider. Camera-led
coverage and loading time on the Intel Mac, plus the published artifacts, still
need physical verification. This release does not claim complete whole-world
coverage or a measured under-five-second detailed-tile time.

## Installation and release status

Install the matching desktop update. On Intel macOS, quit MSC 2, replace the
app, and use **Repair agent** so the service runs the matching bundled agent
and Bedrock map exporter. Existing servers and worlds are retained. Headless
hosts update through the existing local agent installation flow.

The build-only release workflow produces the nine desktop and headless
artifacts, SHA-256 checksums, and signed update metadata. The installers are
not publisher-signed or notarized. Successful publication does not close the
separate physical release acceptance gate.
