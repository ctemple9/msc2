# MSC 2 v0.1.33

This prerelease gathers the macOS installation and first-use improvements from
Cameron's 0.1.32 testing, along with focused server-management and Handbook
changes. These changes still need verification in the downloaded artifacts.

## macOS installation

- The macOS desktop app is built with Cameron's Developer ID certificate and
  submitted for notarization. The release build checks the app signature,
  Gatekeeper assessment, and stapled ticket. Cameron still needs to open the
  downloaded DMG and app on a clean Mac to confirm the first-open experience.
- The DMG opens in a smaller Finder window with MSC 2, Applications, and a clear
  drag arrow. The volume icon resource remains in the image.

## Setup and server management

- First-time Setup explains its three choices in a vertical list and marks
  optional pages more clearly. The Playit page warns existing free-account
  users about agent and tunnel limits.
- Xbox Broadcast uses one helper JAR per agent and shares sign-in across
  participating servers. Its Components row has a menu for downloading and
  enabling or disabling broadcast on the selected server.
- Java runtime detection checks installed runtimes concurrently. The first
  tour card and its controls have clearer copy and placement.
- Server version changes now live in the server component menu. Simulation
  distance is labeled in chunks. The active world opens selected in Worlds,
  and its Overview thumbnail offers shortcut actions.
- Changing the active Java world's game mode updates players online. Java
  Creative console commands have more accurate confirmation behavior, and
  transient console notices can be dismissed.

## Guides

- The Handbook has a welcome note, a full-height contents list, favorites
  managed through a title's context menu, in-app topic links, and Back
  navigation. The first Java, modded Java, and Bedrock guides now follow the
  actual MSC 2 creation flow.
- Router Guide picker rows show each router name once. The Port Forwarding
  Handbook page links directly to the Router Guide picker.

## Installation and verification

Install the matching desktop update. On Intel macOS, quit MSC 2, replace the
app, and use **Repair agent** so the service runs the matching bundled agent.
Existing servers and worlds are retained. Headless hosts update through the
existing local agent installation flow.

The build-only workflow produces nine desktop and headless artifacts, SHA-256
checksums, and signed update metadata. Windows and Linux installers and the
standalone headless archives remain unsigned. Successful publication does not
close the separate physical release acceptance gate.
