# MSC 2 v0.1.34

This candidate carries the macOS installation, first-use, server-control, and
Handbook changes described in the [v0.1.33 candidate notes](v0.1.33.md). The
v0.1.33 build failed Apple notarization and was not published.

## macOS signing correction

The release workflow now signs the bundled `msc`, `bedrock-map`, and `vantage`
executables before Tauri builds the macOS app. The Intel build also signs
`BedrockSidecar` with its virtualization entitlement. Each helper is checked
for a Developer ID signature, hardened runtime, and secure timestamp before
the notarization step. The Intel helpers passed those checks locally.

The downloaded app still needs a clean-Mac Finder first-open check after this
release publishes. Windows and Linux installers and the standalone headless
archives remain unsigned. The build-only workflow still requires the complete
nine-artifact set, checksums, and signed update metadata before publication.
