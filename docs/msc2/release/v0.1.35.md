# MSC 2 v0.1.35

This candidate carries the app changes described in the
[v0.1.33 candidate notes](v0.1.33.md) and the macOS helper-signing correction
described in the [v0.1.34 candidate notes](v0.1.34.md). Neither earlier
candidate was published.

Apple accepted and stapled both v0.1.34 macOS apps. That workflow stopped
afterward because its verification step searched for an app directory that
Tauri had removed after creating each DMG. This candidate verifies the signed,
notarized app inside the finished DMG instead. The verification still checks
the app signature, Gatekeeper assessment, and stapled ticket.

Publication requires all nine desktop and headless artifacts, SHA-256 checksums,
and signed update metadata. Cameron's clean-Mac first-open check remains open
until he installs this exact downloaded release.
