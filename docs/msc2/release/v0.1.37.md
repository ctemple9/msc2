# MSC 2 v0.1.37

This release includes the Intel macOS Bedrock terrain renderer fix confirmed by
Cameron on the second Intel Mac with the same world. On Intel macOS, Vantage now
uses libdeflate’s portable Adler-32 routine when checking compressed region
data. The previous architecture-specific routine crashed during renderer startup
on that host. Bedrock conversion and other architectures are unchanged.

The build-only release workflow still requires all nine desktop and headless
artifacts, SHA-256 checksums, and signed update metadata before publication.
