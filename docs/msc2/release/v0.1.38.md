# MSC 2 v0.1.38

This release includes the Intel macOS Bedrock terrain renderer fix confirmed by
Cameron on the second Intel Mac with the same world. Intel macOS uses libdeflate’s
portable Adler-32 routine when checking compressed region data. The renderer build
preserves libdeflate’s required Zig 0.16 compiler flags on Linux and Windows too.

The v0.1.37 tag was not published. Linux and Windows builds failed because those
flags were omitted from the separately compiled checksum source. Intel macOS
notarization-ticket validation also encountered a lost connection to Apple's
CloudKit service. The v0.1.38 workflow uses a new immutable tag and retries only
that specific transient ticket lookup failure.

The build-only release workflow still requires all nine desktop and headless
artifacts, SHA-256 checksums, and signed update metadata before publication.
