# MSC 2 v0.1.39

This prerelease brings the restored host-local terminal interface to packaged
desktop and headless installations, adds a local agent indicator, and includes
the fixes made since v0.1.38.

- Run `msc tui` locally or through SSH on the computer hosting the agent. It
  includes server creation and management, the seven server tabs, console and
  command palette, storage controls, host settings, and the handbook.
- Desktop users get a helmet in the system bar while the local agent runs.
  The companion stays independent of the desktop window and follows an idle
  local connection without periodic HTTP health checks. Show or hide it from
  the local Agent page. Linux requires a desktop with tray support.
- Windows TUI text-file editing uses Microsoft Edit. If unavailable, install
  it with `winget install Microsoft.Edit`. macOS and Linux retain nano.
- Intel macOS terrain-region decoding uses system zlib. Additional fixes cover
  Xbox Broadcast account reuse, first-start progress, Java stop handling, and
  world-pack controls.

After updating a desktop installation, use **Repair agent** if the local
service still uses an older build. The indicator requires the updated agent's
local lifecycle connection. Headless packages do not install a graphical
indicator or acquire desktop dependencies.

This remains a prerelease. Native Windows/Linux TUI and indicator behavior
requires physical platform verification; successful packaging is not complete
product acceptance. Apple Silicon Macs support local Java and remote hosts;
local Bedrock requires an Intel Mac.

The build-only publication workflow requires all nine desktop/headless
artifacts, SHA-256 checksums, and signed update metadata. macOS desktop apps
and disk images retain Developer ID signing, notarization, and stapling.
