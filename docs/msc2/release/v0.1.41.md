# MSC 2 v0.1.41

This prerelease fixes an Intel macOS terrain-renderer startup crash observed
while opening an All the Mods 10 world.

The renderer now reserves space for macOS signing metadata. Previously,
signing could overwrite the first instructions of its checksum code, causing
a crash while reading the world spawn. A local Intel release build preserves
all instruction bytes across signing and passes strict signature verification.
The same world still requires owner verification in the published build;
this release does not claim world corruption or complete modded-block support.

After installing the updated desktop app, use **Repair agent** to ensure the
local service uses the matching renderer, then reopen the map.

The Apple Silicon build uses the supported macOS 15 runner. Publication stays
build-only, with all nine desktop/headless artifacts, SHA-256 checksums, and
signed update metadata. macOS desktop apps and disk images retain Developer ID
signing, notarization, and stapling. Physical verification is deferred to Cameron.

This replaces the unpublished v0.1.40 candidate. Disk-image stapling now retries
Apple’s explicit connection-loss error up to three times, matching ticket
validation. Other signing or ticket errors still stop publication.
