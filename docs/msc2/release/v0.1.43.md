# MSC 2 v0.1.43

This release preserves the v0.1.42 feature set and macOS signing fixes, and adds:

- Recovery instructions for incomplete Playit setup, including local reset and cleanup of the failed attempt in the Playit account.
- Persistent per-server Java selection for creation, startup, version changes and desktop/TUI server editors. The host default remains a fallback. Duplicate Windows Java paths are collapsed.
- Automatic local agent service status refresh with clear failures and a manual refresh action.
- A baseline CPU target for the Windows terrain renderer, avoiding release-runner-specific SHA instructions that crashed on older Intel CPUs. macOS and Linux renderer build commands are unchanged. Physical map verification remains pending.

Includes all nine platform packages, checksums and signed update metadata. Retains macOS signing, notarization and ticket transport workarounds. No test suites were run. Source checks do not establish physical acceptance on every operating system.
