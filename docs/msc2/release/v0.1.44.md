# MSC 2 v0.1.44

- Modrinth and CurseForge mod and modpack browsing share consistent sheets, with direct mod installation and clearer creation compatibility handling.
- Export the original modpack plus your changes, or current server content. Retained client mods, shaders and resource packs stay available for player exports; additions, removals, disabled mods and active-world datapacks are reflected automatically.
- Export folders are nested, missing local files are documented in the README, and optional launcher-importable .mrpack files can be included.
- Faster export preparation, ZIP creation and local saving, with progress and cancellation throughout.
- Intel Mac installers include the Bedrock VM helper, kernel and appliance image. The release packaging inspects these resources inside the finished disk image. Enabling the privileged helper can still require macOS authorization.

Apple Silicon supports Java and remote Bedrock management; local Bedrock still requires an Intel Mac. Existing offline instructions are included; illustrated launcher guides remain deferred.

All nine platform packages, checksums and signed update metadata are required for publication. No test suites were run. Build and packaging checks do not establish fresh-install or full physical acceptance on every platform.
